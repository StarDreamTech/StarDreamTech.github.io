星笺Starclip

剪贴板管理器

v0.2.5

Rust 驱动的本地优先剪贴板管理器，让每一次复制都有迹可循。

  • 记录文本、图片与文件路径，SQLite 本地持久化，去重、搜索与分类筛选
  • 星码集收藏代码片段；星绘坊把代码和文字做成分享卡片、手写纸笺
  • 简体中文 / English 界面，应用内签名校验更新
RustmacOS · Apple SiliconWindows x64
brew install --cask stardreamtech/tap/starclip

星镜Starshot

截图 · 标注 · 贴图

v0.3.2

本地优先的桌面截图、标注、贴图与图片美化工具。把灵感，定格成星。

  • 窗口边界吸附选区、多显示器、延时截图，竖向 / 横向长截图
  • 箭头、序号、马赛克等标注，本地识别手机号、邮箱等敏感信息一键打码
  • 置顶贴图；渐变背景、圆角阴影美化，导出 PNG / JPEG
Rust · Tauri 2 · Vue 3macOS 12+ · Apple SiliconWindows x64

星匣StarVault

AI 对话档案

v0.1.4

你的 AI 记忆，始终属于你。本地优先的 AI 对话档案：增量备份、附件与 Skill 迁移，提供桌面端、CLI 和 MCP。

  • 收集 Codex、Claude Code、Claude Desktop、WorkBuddy、OpenClaw、DeepSeek Harness 会话，可导入 ChatGPT 对话
  • 私有 GitHub 仓库只同步对话正文与索引，附件和原始记录留在本地
  • 通过 MCP 让助手检索已有档案

Homebrew Tap

一行命令，装上星星

星梦科技维护的 Homebrew 安装源，当前桌面应用支持 Apple Silicon Mac。Windows 安装包请到各项目的 Release 下载。

应用为 ad-hoc 签名，尚未通过 Apple 公证，首次打开时 macOS 可能会拦截，请先阅读各版本的发布说明。

zsh
# 星笺 · 剪贴板
$ brew install --cask stardreamtech/tap/starclip
# 星镜 · 截图
$ brew install --cask stardreamtech/tap/starshot
# 星匣 · AI 对话档案
$ brew install --cask stardreamtech/tap/starvault
