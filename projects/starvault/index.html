星匣StarVault

AI 对话档案

v0.1.4

你的 AI 记忆，始终属于你。

星匣是本地优先的 AI 对话档案：增量备份、附件与 Skill 迁移，提供桌面端、CLI 和 MCP。它把分散的对话、附件与 Skill 收进自己的长期档案，方便检索、回溯和换机迁移。

产品原名 Chat History Vault（会话档案）。starvault 与 chat-history-vault 命令都可以使用。软件代码在公开仓库；聊天备份使用你自己配置的私有仓库。最新正式 Release 为 v0.1.4。

PythonRust · eguiCLIMCPMIT

主要功能

  • 收集 Codex、Claude Code、Claude Desktop、WorkBuddy、OpenClaw、DeepSeek Harness 的本地会话，也可以导入 ChatGPT 对话。Claude Desktop 包括已经保存在本地的云端聊天导入副本，以及 Code Projects 的本地缓存消息；不会登录云端去抓取新聊天。
  • 私有 GitHub 仓库只同步对话正文与分类索引。原始消息记录、附件、命令和日志留在本地。公开的软件仓库不存放聊天内容，备份同步会校验目标是私有仓库。
  • 桌面阅读器使用 Rust + egui，直接读取同一份本地备份，不启动网页服务器。可以按来源筛选、全文搜索、按项目查看时间线，并阅读 Markdown 与本地原图。
  • 命令行统一做备份、查询、附件复制和 Skill 迁移。查询已有档案不需要先 init，也不需要登录 GitHub。
  • MCP 与桌面端读取同一份档案，通过标准输入输出通信，不打开网络端口。默认提供状态、检索、分页阅读、附件与 Skill 列表，以及空间估算；配置里加入 --allow-write 后才提供备份和恢复。
  • 图片按内容 SHA-256 去重，保存在本地，不压缩、不上传。Skill 以完整目录的 ZIP 快照留在本地，可以恢复到指定文件夹。复制整个备份文件夹才能带走原文、图片和 Skill；只克隆 GitHub 上的文字分支不够。

依赖：Python 3.9 及以上；备份需要 Git，向私有仓库同步需要 GitHub 登录。运行时没有必装的第三方 Python 包。这是阅读与检索归档，README 写明不保证能导回原来的应用、继续同一个会话。

当前版本 v0.1.4

以下摘自已发布的 StarVault v0.1.4 说明。这一版改进阅读和筛选，不修改原始会话，也不改后端导出或导入格式。

  • 筛选、项目 / 会话列表和正文使用独立三栏。来源显示会话数量，常用条件可以直接点选，已选条件可以单独去掉。
  • 浅色工具栏与居中限宽的正文。真实提问使用浅灰气泡，助手回复连续排版，并保留来源、时间和原文复制。
  • 根据本地原始消息的元数据，折叠已经确认的 Skill、Agent 协作与辅助上下文；关联的工具图片和完整原文仍然保留。
  • 软件仓库根目录提供 npm run preview 和 npm run preview:timeline，用来启动源码预览和时间线视图。

支持平台

  • 桌面安装包：Apple Silicon macOS当前 Release 提供 StarVault-0.1.4-macos-arm64.zip。应用使用本机临时签名，尚未通过 Apple 开发者签名和公证。
  • 桌面端的其他系统README 写明 Intel macOS、Windows、Linux 的桌面端目前从源码构建，不要把它们称为已有可下载的原生安装包。macOS 构建在本机验证过；Windows / Linux 打包尚未验证。
  • CLI / MCP：macOS 与 Linux组织首页对应的命令是下面的 formula。Windows 可以按 README，在源码的虚拟环境里安装命令行，没有单独的 Windows 安装包。

Python 后端已通过 macOS / Windows / Linux 的 CI 临时数据回归。README 写明：源应用的真实数据读取，目前只在 macOS 本机核验。Windows / Linux 上的 MCP 客户端真机接入尚未验证。

安装

与组织首页相同。桌面 Cask 会同时带上 CLI 和 Python 后端：

brew install --cask stardreamtech/tap/starvault # 仅 CLI / MCP brew install stardreamtech/tap/starvault

项目 README 还记录了个人 Tap 的写法：先 brew tap cpython666/tap，再 brew install starvault（CLI / MCP，macOS / Linux）或 brew install --cask starvault（桌面应用，Apple Silicon macOS）。本页的可复制命令与组织首页一致，使用 stardreamtech/tap。

v0.1.4 Release 里的文件：

  • StarVault-0.1.4-macos-arm64.zip Apple Silicon macOS 桌面端
  • StarVault-0.1.4-source.tar.gz 源码包，不是各平台桌面安装包

若 macOS 阻止打开，README 建议先核对下载来源和 SHA256，再按「系统设置 → 隐私与安全性」的提示允许打开。发布包只包含软件与固定素材，不包含聊天数据或本机配置。
