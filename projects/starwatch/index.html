星哨StarWatch

网页监控 · 接口探活

开发中

可自托管的定时监控平台，按指定字段监测网页和接口，并比较历史内容。

已实现任务调度、内容提取、历史版本对比和通知。调度器保存任务与运行记录，抓取器负责发请求，前端查看结果。按单副本调度器部署，完整配置以仓库 README 为准。

Vue · FastAPI · MongoDBDocker ComposeMIT

当前状态：已提供实现代码与 Docker Compose 启动方式，尚无正式 Release 或独立安装包。

项目能力与进度

  • cron 与时间间隔调度，支持网页监控、接口断言和短时压测
  • HTML、JSON 与文本提取，逐行查看历史版本的新增、删除和修改
  • 任务、运行记录、快照与通知，抓取器和调度器分离

平台与交付方式

以 Web 服务形式自行部署，通过浏览器使用；目前没有独立桌面安装包。

从源码开始

以下为仓库 README 中的启动入口，完整依赖和配置请先阅读原始文档。

docker compose up --build
