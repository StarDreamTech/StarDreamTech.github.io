星笺Starclip

剪贴板管理器

v0.2.5

Rust 驱动的本地优先剪贴板管理器，让每一次复制都有迹可循。

本地剪贴板管理工具，让剪贴板不止记住上一次。星笺使用 Rust 构建，把复制过的文字、链接和代码收进历史，整理成星标与分组，再通过星绘坊做成代码卡片或手写纸笺。

技术栈是 Rust + Tauri 2 + SQLite + Vue 3 + TypeScript + Vite。无需账户，剪贴内容保存在本机。最新正式 Release 为 v0.2.5。

RustTauri 2SQLiteVue 3MIT

主要功能

  • 剪贴历史：记录系统剪贴板中的文本、图片与文件路径引用，SQLite 本地持久化，支持去重、搜索与分类筛选。图片可看缩略图和原图；文件只保存路径，不读取文件内容。
  • 自己的星系：星标收藏、永久保留、彩色分组，以及卡片、列表、流星栏。星尘整理会先预览再清理，星标和永久保留的记录始终跳过。
  • 星码集：收藏、编辑代码片段，带语法高亮、行号和 JSON 格式化，可导出 Markdown 与 PNG 卡片。
  • 星绘坊：星码卡把代码排成分享图，月光笺把文字排成手写纸笺。月光笺使用内置手写引擎，选中的字体下载后可离线导出 PNG。0.2.5 起可在主界面制作 Markdown 图片。
  • 外观与语言：星夜、月白、素白、青苔、暮樱五套主题，可跟随系统；也能改强调色、渐变，并导入一张本地 PNG 贴纸。界面可选跟随系统、简体中文或 English。
  • 随用随取：默认呼出键为 ⌘/Ctrl + Shift + V，可在偏好设置里修改；提供菜单栏 / 托盘。应用内可检查更新，安装前做 Tauri 签名校验。
  • 星伴：可选的原创桌面角色「星芽」，默认关闭，不读取剪贴内容。这是星笺里的陪伴功能，不是首页上尚未推出的星伴 StarBuddy。
  • 隐私与本机 AI：支持本地敏感检测、关键词和精确域名规则。MCP、数据 CLI 与 Skill 默认关闭，历史读取只返回明确选中的记录和字段。

README 的产品范围写明：GIF 动画、OCR、跨设备同步、公开分享链接、多片段分享页、备注、自动粘贴、在线运行和 AI 解释尚未实现。剪贴内容以明文、未加密的形式保存在本机。检查更新会连接 GitHub 获取更新信息，不上传剪贴内容。0.2.4 起可选使用统计有三种模式：不发送、每次运行随机编号（缺省）、本机固定随机编号；统计不含剪贴内容。

当前版本 v0.2.5

以下摘自已发布的 星笺 v0.2.5 说明。GitHub 记录的发布时间是 2026-11-10 16:42 UTC。

  • 新增 Markdown 图片：素纸、星紫、深夜三款本地主题，可调宽度和字号，并导出 2 倍 PNG。
  • 一条记录可以保存配文和多张静态图片；图片去重会比较字节或像素，避免只凭摘要误判。
  • 图片支持多选、复制为独立 PNG 文件列表、导出到目录，以及原生拖出入口。
  • 图片查看增加缩放、平移、全窗口预览；历史页增加数字页码，并记住分类、分组和设置页位置。
  • 星标收藏可按最近更新、最近收录、复制次数或自定义顺序排列；分享素材可以直接加入收藏。
  • 数据结构与 JSON 备份升级为 5，可导入 JSON v1–v5。旧版不能直接打开新结构数据库。

同一份发布说明写明：macOS WebKit / Windows WebView 的原生 PNG 导出尚未专项验收；Windows 多图粘贴，以及两个平台的最终拖放收件，尚未完整验收。

支持平台

  • Apple Silicon Mac（M 系列，macOS 11+）Homebrew Cask 与 Release 中的 DMG。Cask 只提供 arm64。
  • Windows x64Release 中的安装程序。没有单独的 Homebrew 命令。

README 没有把 Intel Mac 或 Linux 列为当前可下载的安装包。macOS 应用使用 ad-hoc 签名，尚无 Apple Developer 公证；Windows 尚无发行者证书。更新包另有 Tauri 签名校验。

安装

与组织首页相同，使用星梦科技的 Homebrew Tap：

brew install --cask stardreamtech/tap/starclip

项目 README 还记录了同一份 Cask 的个人 Tap：brew install --cask cpython666/tap/starclip。若 Homebrew 提示这份 Cask 未受信任，README 写明可按安装来源执行 brew trust --cask stardreamtech/tap/starclip 后重试。

也可以从 GitHub Release 下载安装包：

  • Starclip_0.2.5_aarch64.dmg Apple Silicon macOS
  • Starclip_0.2.5_x64-setup.exe Windows x64

首次打开时 macOS 可能会拦截尚未公证的应用。安装前请先阅读该版本的发布说明，并用 Release 页面上的 SHA256SUMS 核对文件。
