星镜Starshot

截图 · 标注 · 贴图

v0.3.2

本地优先的桌面截图、标注、贴图与图片美化工具。把灵感，定格成星。

星镜使用 Rust / Tauri 2 / Vue 3 / TypeScript，中文界面和五套外观沿用星空系列，作为独立产品开发，不包含桌面宠物。当前版本 0.3.2，已进入应用内更新通道，macOS 与 Windows 同为目标平台。

浏览器可以体验导入图片、标注、美化与下载；浏览器里的截图是标明的原创示例。真正的桌面截图和置顶贴图只在原生版提供。

RustTauri 2Vue 3macOS 12+Windows x64

主要功能

  • 截图：按需冻结多显示器画面，吸附系统窗口边界，支持手动框选、八向调整、拖动、1px / 10px 键盘微调、放大镜和 HEX 读数。可延时 3 / 5 / 10 秒，也能导入 PNG / JPEG / WebP。
  • 标注：截图后在选区下方直接使用箭头、矩形、椭圆、画笔、荧光笔、文字、序号、马赛克和实心遮盖，可撤销、重做、复制、保存和贴图。主动选择「更多编辑」才进入完整页面。
  • 敏感信息：主动在本地识别手机号、邮箱、证件、银行卡和常见凭据，预览勾选后再实心打码。macOS 支持中英文；Windows 主要支持拉丁文字和数字。扫描不含装饰背景，仍需复核漏检。
  • 美化与导出：渐变、纯色、透明或本地图片背景，以及留白、圆角、边框、阴影。画布可选自适应、1:1、4:3、16:9、9:16。同一 Canvas 预览并导出 PNG / JPEG，可选 1× / 2×。
  • 置顶贴图：拖动、缩放、旋转、翻转、调整透明度，并可隐藏工具条。贴图可双击关闭，右键复制、另存或送到编辑器。
  • 长截图：竖向向下或横向向右拼接，可主动开始自动滚动，也可用 Esc / 空格暂停并手动补采。页面不稳定或拼接失败时停止自动模式，并保留已有结果。
  • 外观与驻留：星夜、月白、素白、青苔、暮樱和自定义配色。可配置全局热键、可选开机启动和启动到托盘。设置内可手动检查更新，下载并校验签名后再安装重启。

README 中的快捷键：⌘/Ctrl + Shift + 2 开始截图，⌘/Ctrl + Alt + 3 贴出最近截图原图。编辑器支持 ⌘/Ctrl + S 导出、⌘/Ctrl + Z 撤销、⌘/Ctrl + Shift + Z 重做。macOS 首次截图需要允许屏幕录制权限。星镜不规划持久截图历史，长期剪贴板历史由星笺负责。

README 同时写明仍待补齐或待验收的范围：系统控件识别的真实跨应用命中、复杂页面的长截图、独立全文 OCR 与 Windows 中文模型、跨屏连续选区、贴图分组、GIF。长截图尚不支持向上或向左反向拼接。星镜不是已达到参考产品全部功能的成品。

当前版本 v0.3.2

以下摘自已发布的 星镜 v0.3.2 说明。GitHub 记录的发布时间是 2026-11-10 16:26 UTC。旧版需要下载更新并确认「安装并重启」才会换成新交互。

  • 新增长截图：竖向向下、横向向右拼接；用户主动开始自动滚动，也可手动逐屏补采。可暂停后复制、保存、贴图或继续编辑。
  • 截图操作：右键先重选、再退出；Tab / Shift+Tab 沿候选层级扩大或返回；H 切换辅助线；C 复制原像素色值。
  • macOS 在已有辅助功能授权时只查询控件角色与几何，不读取界面文字。macOS 27 及以上的截图覆盖层加入系统热角保护，旧系统保守回退。
  • 设置重整为五个标签，主题入口独立。快捷键支持按键录入和占用检测。托盘增加分组、贴图显隐与计数，以及本次运行的快捷键暂停。
  • 分享文案和原创产品图先预览，确认后再复制。macOS 仍为 ad-hoc 签名且未 Apple 公证，Windows 未配置发行者证书。

支持平台

  • Apple Silicon Mac，macOS 12+Homebrew Cask 与 Release 中的 DMG。macOS 使用系统 Vision 做本地识别，无需另下模型。
  • Windows x64Release 中的 NSIS 安装包。离线 OCR 模型约 12.2 MB，随安装包内置，主要识别拉丁文字和数字。

两平台更新包都有独立的 Tauri 更新签名。这不等于 Apple 公证或 Windows 发行者签名。README 没有提供 Intel Mac 或 Linux 安装包。

安装

与组织首页相同，使用星梦科技的 Homebrew Tap：

brew install --cask stardreamtech/tap/starshot

项目 README 的安装节目前写的是个人 Tap：brew install --cask cpython666/tap/starshot。组织首页与本页使用上面的组织 Tap 命令。

Windows x64 安装包和 macOS DMG 见 0.3.2 Release：

  • Starshot_0.3.2_aarch64.dmg Apple Silicon macOS
  • Starshot_0.3.2_x64-setup.exe Windows x64

macOS 尚未 Apple 公证，首次打开可能会被拦截。请先阅读发布说明，并用 Release 页面上的 SHA256SUMS 核对文件。0.1.0 没有应用内更新，需要手动升级后才能使用更新通道。
