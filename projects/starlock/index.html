星锁StarLock

人机验证 SDK 与服务

v0.8.0 · 开发版

面向网站与 Web 应用的验证码组件、挑战 API 与服务端复核。

星锁提供统一的会话、挑战与凭证流程，已实现数字、字符、算术、直线拼图、曲线拼图、圆环旋转、文字点选和语义九宫格八种题型。前端通过托管脚本加载验证码，也可以在 Vue 3 或 React 18/19 中使用同一份 SDK。

已实现的验证方式

  • 传统图片验证支持纯数字、字母数字与算术题，输入答案后由服务端校验。
  • 直线拼图和曲线拼图分别控制运动路径与贝塞尔速度缓动，并同步改变图形角度。
  • 拼图、五角星、正方形和长方形可生成多个缺口，仅一个位置与角度能够匹配。题面约束行程、边界与缺口间隔。
  • 圆环题通过滑块旋转内圈，与固定外圈恢复对齐，交界处采用轻度模糊与羽化处理。
  • 验证码默认使用紧凑弹窗，支持关闭按钮、遮罩点击、Esc 与键盘微调，关闭后恢复触发控件焦点。

接入你的业务

  1. 业务后端用站点密钥创建验证会话，绑定本次业务动作与上下文，将短期票据交给浏览器。
  2. 浏览器加载托管 api.js，调用 StarLock.render()，或使用 Vue / React 组件展示挑战。
  3. 验证完成取得 token 后，将其随业务请求交给后端。后端调用 /v1/siteverify 复核并消费一次性凭证，再执行业务。

挑战与答案校验由 FastAPI 服务负责，Redis 保存短期状态，SQLite 保存本地站点配置。接入来源按站点授权，站点密钥保存在业务后端。

本地运行需要 Python、Node.js 与 Redis。可以直接打开在线 demo，体验八种验证方式、换题与键盘操作。演示在浏览器内判定，应用接入时使用服务端校验。源码也提供完整启动、配置和测试说明。

星锁常见问题

星锁 StarLock 是什么？

星锁是星梦科技的开源人机验证项目，提供验证码前端组件、托管 JavaScript SDK 和 FastAPI 后端服务，源码采用 MIT 许可证。

支持哪些验证码？

当前已实现字符、数字、算术、直线拼图、贝塞尔曲线拼图、圆环旋转、文字顺序点选和静态语义九宫格。多轮换图、无感验证与行为评分仍在开发计划中。

普通网页、Vue 和 React 怎样接入？

普通网页加载托管 api.js，Vue 3 和 React 18.2+/19 使用相应组件封装。业务后端创建会话，前端完成挑战取得 token，再由业务后端调用 /v1/siteverify 复核。完整步骤和示例见接入文档。

现在可以使用公共 API 或 npm 包吗？

当前提供本地运行源码，公共验证 API、正式 CDN 和 npm 包尚未发布。部署说明、接入代码和验证范围均可在项目仓库查看。

StarLock is an open-source CAPTCHA SDK and verification service by StarDreamTech. It supports six challenge types, vanilla JavaScript, Vue 3, and React 18.2+/19. Verification tokens are checked by the application backend. Source code is available under the MIT license. Public hosted APIs and npm packages are not yet released.
