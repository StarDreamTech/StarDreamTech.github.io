星使StarEnvoy

BOSS 岗位筛选助手

源码阶段

按地区、关键词、薪资和经验筛选 BOSS 岗位，集中查看结果与沟通记录。

采集条件可以保存，结果支持打开岗位页与查看完整描述。浏览器登录状态和沟通历史保存在本机。自动沟通由使用者在采集设置中选择开启。

Python · PySide6DrissionPage · uv

当前状态：已有功能源码，尚未发布独立安装包；使用时需在浏览器完成自己的登录与验证。

项目能力与进度

  • 采集设置、岗位结果、沟通记录和采集日志四个标签页
  • 按条件筛选岗位，查看职位详情并导出 CSV
  • 可选匹配后打招呼，记录沟通时间与历史

平台与交付方式

当前提供 Python 源码启动方式，尚未发布按操作系统划分的安装包。具体环境要求见仓库。

从源码开始

以下为仓库 README 中的启动入口，完整依赖和配置请先阅读原始文档。

uv sync
uv run python main.py
