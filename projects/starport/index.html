星口StarPort

本地代理端口管理

原型阶段

从本机 Clash 配置挑选少量节点，每个节点分配一个本地 SOCKS 端口，用页面管理启停。

管理页仅在本机监听。选中节点写入受管运行配置，订阅地址和节点密码不会展示在页面上。新增和删除先保存列表，启动时才应用端口变更。

Go · mihomo本机 Web 管理页

当前状态：已有首版实现，尚无正式 Release；需自行构建并准备本机配置与 mihomo。

项目能力与进度

  • 页面增删出口、配置端口，统一启动和停止
  • 仅管理自己启动的 mihomo，保留现有 Clash 系统代理设置
  • 提供本机状态与出口接口，供工具和 AI 调用

平台与交付方式

当前 README 提供本机构建与配置方式，记录了 Apple Silicon Mac 的测量结果；其他平台支持情况以仓库验证为准。

从源码开始

以下为仓库 README 中的启动入口，完整依赖和配置请先阅读原始文档。

go build -o starport ./cmd/starport
cp config.example.yaml config.yaml
./starport
