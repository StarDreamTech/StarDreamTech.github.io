星芽桌面助手

第 0 期

围绕原创角色星芽构建个人电脑助手，目前已有前端外壳与成长系统预览。

项目正在从星笺拆出星芽角色，仓库包含前端代码与网关协议草案。透明桌面浮窗、拖动贴边需要接入桌面工程；守护进程与 Agent 适配器尚未实现。

Vue · TypeScript · Vite前端预览MIT

当前状态：当前预览使用内存演示数据，尚不能调度 Claude Code、Codex 等本机 Agent。

项目能力与进度

  • 星芽表情、动作、互动菜单与成长系统
  • 前端外壳可在浏览器中预览
  • 桌面工程、守护进程与 Agent 调度适配待实现

平台与交付方式

目前可在浏览器预览前端外壳，尚未提供独立桌面安装包。

从源码开始

以下为仓库 README 中的启动入口，完整依赖和配置请先阅读原始文档。
